# Aayush Sinjon — Personal Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local development server, run:
```bash
python -m http.server 8000
```
Then open http://localhost:8000.

## Deploy on Vercel
1. Create a GitHub repository (for example `aayush-portfolio`).
2. Upload the contents of this folder to the repository root (`index.html`, `style.css`, `script.js`, and `assets/`).
3. Sign in at https://vercel.com/ using GitHub.
4. Select **Add New → Project**, import the repository, and deploy.
5. Framework preset: **Other**. Build command: leave blank. Output directory: `.` (or leave the default if detected).
6. Vercel will give you a public `*.vercel.app` URL.

You can also use GitHub Pages: repository Settings → Pages → Deploy from a branch → `main` / root.

## Before publishing — personalize these
- Replace the generic LinkedIn and GitHub links in `index.html` with your actual profile URLs.
- Add real project repository/demo links when available.
- Check that the resume PDF is current and that you want your phone number publicly visible.
- The project descriptions are intentionally framed as a team build / practice project; update them to reflect the exact status and your contributions.
- If you buy a custom domain, add it in Vercel Project → Settings → Domains, then follow Vercel's DNS instructions.
